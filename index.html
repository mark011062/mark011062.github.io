Projects

Shelter Return Analysis

An analysis of 84,143 Austin Animal Center adoption events examining factors associated with animals returning to the shelter within 30 days of adoption.

The analysis identified a 6.40% overall 30-day return rate and found meaningful associations between returns and animal type, age, and prior shelter history.

The project includes data cleaning, feature engineering, exploratory analysis, statistical modeling, visualization, and an interactive Streamlit dashboard.

Technologies: Python, Pandas, Matplotlib, Statsmodels, Jupyter, Streamlit, Git, GitHub

Austin Pet Adoption Data Pipeline

An end-to-end data engineering project that transforms raw Austin Animal Center data into an analytics-ready dimensional data warehouse.

The pipeline handles ingestion, data cleaning, feature engineering, validation, dimensional modeling, analytical marts, and machine-learning dataset generation using a DAG-style workflow.

The project also includes a FastAPI service for analytics and machine-learning predictions, including a model that predicts whether an animal will be adopted within 30 days.

The tool combines domain knowledge from sewer inspection workflows with Python automation to reduce repetitive manual QA work and improve deliverable consistency.

Media Quality Automation Tool

A Python desktop application that automates video quality validation and identifies corrupt or problematic MP4 files before analyst review.

The tool uses FFmpeg to validate media files in batches and provides a Tkinter interface so the process can be used by non-technical users.

The automation reduced a manual media review process from approximately two hours to about 15 minutes per day while improving consistency in media quality checks.

Technologies: Python, FFmpeg, Tkinter, Automation, PyInstaller
